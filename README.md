# LiturAngler Legal Docs

Static hosting for the Privacy Policy, Terms of Service, and Support pages required by App Store Connect for Litura, CastCount and CatchHook.

Kept separate from [liturangler.com](https://www.liturangler.com) so the marketing site can be rebuilt independently without affecting the URLs registered with Apple.

Served via GitHub Pages from this repo's `main` branch.

- `litura-privacy.html`
- `litura-support.html`
- `castcount-privacy.html`
- `castcount-terms.html`
- `catchhook-privacy.html` — CatchHook（鱼乐日记）, generated from the app's in-app `privacy_policy.{zh-Hans,en}.md`
- `catchhook-terms.html` — generated from the app's in-app `terms_of_service.{zh-Hans,en}.md`

Litura's Terms of Service has no real page yet (`litura-support.html` links to it as "coming soon") — needs to be written and added before it's referenced anywhere as final.
